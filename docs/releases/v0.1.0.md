RustGet 0.1.0 — first public build.

## Standalone desktop app

This build ships `rustget-desktop.exe`: the daemon and local API run in-process
and the UI opens in a native WebView2 window. No external browser is used. The
MSI Start Menu shortcut launches the desktop app.

## Installer

- `RustGet-0.1.0-x64.msi` installs per-machine to `Program Files\RustGet`, creates a Start Menu shortcut to `rustget-desktop.exe`, and bundles `WebView2Loader.dll`.
- Target: Windows x86-64. A 32-bit x86 build is not included.
- The MSI is unsigned; Windows SmartScreen may warn.

## Portable

- `rustget-0.1.0-windows-x64.zip` contains the desktop/CLI/native-host/tray binaries, WebView2 loader, docs, extensions and `install-windows.ps1` for a per-user install.

## Verification

- 133 tests pass; fmt and strict clippy are clean.
- MSI payload verified with WiX `dark.exe`.

This is an early build; see `docs/specs/13-parity-scorecard.md` for the remaining gaps.
